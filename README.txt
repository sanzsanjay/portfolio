SANJAY — PREMIUM PORTFOLIO

CONTENTS
- index.html: portfolio homepage
- styles.css: visual design, responsive layout, and animations
- script.js: particle background and interactive effects
- Sanjay_Resume.pdf: resume download
- sanjay-portrait.jpeg: personal portrait displayed in the hero section
- vercel.json: Vercel static deployment configuration

PREVIEW
1. Extract this folder.
2. Open index.html in a modern browser.
3. Keep all files together so the portrait, styles, JavaScript, and resume links work.

PUBLISH WITH VERCEL
1. Sign in to Vercel.
2. Import this folder through a Git repository or use Vercel CLI from this folder.
3. Deploy as a static site; no build command is required and the output directory is the project root.
4. Share the public URL returned by Vercel after successful deployment.

The public URL is not created until a deployment is completed in an authorised hosting account.
