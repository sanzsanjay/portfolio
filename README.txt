SANJAY — PREMIUM JOB-READY PORTFOLIO

WHAT'S INCLUDED
- index.html: responsive portfolio content and sections
- styles.css: premium dark theme, responsive layout, animated effects
- script.js: animated particle background, scroll reveal, mobile navigation
- Sanjay_Resume.pdf: resume download linked from the website
- vercel.json: static site deployment configuration for Vercel

PREVIEW LOCALLY
1. Extract this folder.
2. Keep all files together.
3. Open index.html in a browser.

PUBLISH TO A PUBLIC URL ON VERCEL
1. Sign in to Vercel and connect your account when prompted.
2. Import this folder/repository as a project, with the portfolio files in the project root.
3. Framework preset: Other. Build command: leave blank. Output directory: leave blank or use the root directory.
4. Click Deploy. Vercel will provide a public URL ending in vercel.app.

IMPORTANT
The website is prepared for deployment, but it is not live until deployed through a hosting account. Do not share the site publicly until you have checked contact details and resume content. Google Fonts require an internet connection; the website itself is static HTML/CSS/JS.
